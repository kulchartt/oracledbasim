How it works

Three steps from ticket to score

  1. Run Oracle Free locally

    One Docker command, pulled straight from Oracle. Connect with SQL*Plus or SQL Developer, whichever you prefer.

  2. Take a ticket dbasim start s01

    dbasim plants the fault in the database and starts a simulated app with many users. You get a ticket and logs, just like a real shift.

  3. Fix it, then dbasim check

    It checks both the outcome and how you got there. Deleting data to make things faster does not count. Pass, and a senior DBA walkthrough explains the fix.

FAQ

Before you start

Do I need an Oracle license?

No. dbasim runs on Oracle Database Free, which you download from Oracle yourself under Oracle's free-use terms.

How powerful does my machine need to be?

You need Docker, about 3 GB of free RAM and 10 GB of free disk. On a slower machine you can shrink the scenario data size.

Can I run it against a database at work?

No, and you shouldn't. dbasim creates and drops objects, so it is locked to Oracle Free only.

How much does it cost?

The first 3 scenarios (s01–s03) are free forever, with no sign-up and no card. Pro scenarios are not on sale yet.

Install in 4 steps

  1. Install Docker and Python 3.9 or newer.

  2. Start Oracle Database Free with Docker (the first download is several GB).

  3. Install dbasim with pip.

  4. Run dbasim doctor to check the setup, then dbasim start s01.

Full commands and the Windows setup are in the guide on GitHub.

terminalFree
$ docker run -d --name dbasim-oracle -p 1521:1521 \
    -e ORACLE_PWD=ChangeMe123 \
    container-registry.oracle.com/database/free:latest
$ pip install dbasim
$ export DBASIM_ADMIN_PASSWORD=ChangeMe123
$ dbasim doctor
$ dbasim start s01
