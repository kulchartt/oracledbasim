Oracle DBA break-fix lab

ฝึกแก้ DB พังตอนตีสอง ก่อนจะเจอของจริง

dbasim สร้างเหตุการณ์จริงขึ้นใน Oracle บนเครื่องของคุณ มีผู้ใช้จำลองกดระบบอยู่ตลอด คุณหาสาเหตุ แก้ แล้วให้ระบบตรวจว่าแก้ถูกจริงหรือไม่ ไม่ใช่แค่ดูวิดีโอแล้วจบ

เล่นยังไง

สามขั้น จากรับ ticket ถึงได้คะแนน

  1. เปิด Oracle Free ในเครื่อง

    Docker คำสั่งเดียว ดาวน์โหลดจาก Oracle โดยตรง แล้วต่อด้วย SQL*Plus หรือ SQL Developer ที่คุณถนัด

  2. รับโจทย์ dbasim start s01

    ระบบฝังปัญหาเข้า DB และเปิดแอปจำลองที่มีผู้ใช้หลายคน คุณได้ ticket กับ log เหมือนวันทำงานจริง

  3. แก้แล้วตรวจ dbasim check

    ตรวจทั้งผลลัพธ์และวิธีแก้ ลบข้อมูลเพื่อให้เร็วขึ้นไม่นับ ผ่านแล้วได้เฉลยแบบ DBA อาวุโสอธิบาย

ก่อนสมัคร

ต้องซื้อ license Oracle ไหม

ไม่ต้อง dbasim ใช้ Oracle Database Free ซึ่งคุณดาวน์โหลดจาก Oracle เองภายใต้เงื่อนไขการใช้ฟรีของ Oracle

เครื่องต้องแรงแค่ไหน

ต้องมี Docker, RAM ว่างประมาณ 3GB และ disk ว่าง 10GB ถ้าเครื่องช้า ปรับขนาดข้อมูลของโจทย์ให้เล็กลงได้

เอาไปลองกับ DB ที่ทำงานได้ไหม

ไม่ได้ และไม่ควร dbasim สร้างและลบ object ใน DB จึงล็อกให้ทำงานกับ Oracle Free เท่านั้น

ราคาเท่าไหร่

  1. ได้ license key ทางอีเมล

  2. ติดตั้ง dbasim ด้วย pip install dbasim (หรือใช้ตัวที่ติดตั้งไว้แล้ว)
